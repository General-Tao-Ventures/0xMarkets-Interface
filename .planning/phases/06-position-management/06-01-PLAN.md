- This is a GMX-forked codebase. TradeBox, PositionList, PositionItem, OrderStatusNotification all exist as inherited code.
- The trade execution flow is: TradeBox -> useTradeboxTransactions -> sendBatchOrderTxn -> on-chain createOrder -> keeper scans ORDER_LIST -> OrderExecutor calls executeOrder with oracle params -> position created
- State flows through SyntheticsStateContext -> selectors -> components. Positions are fetched via usePositionsInfoRequest (SWR) from subgraph/RPC.
- The order-execution-keeper-service at /Users/ken/Projects/0xM/order-execution-keeper-service/ already has OrderScanner + OrderExecutor that handle market and limit orders.
- All 6 markets are configured on Base Sepolia with pool capacity and OI limits (Phase 4 work).
