         - `lastExecutionTime: Date | null` (null until first successful cycle)

         - `oracleConnected: boolean` (default false)

       - Export `setOracleStatus(connected: boolean)` — updates oracleConnected

    4. Update `/Users/ken/Projects/0xM/order-execution-keeper-service/src/server/httpServer.ts`:
       - Import `healthState` from `../utils/healthState.js`
       - Import `logger` from `../utils/logger.js`
       - Replace the existing `/health` handler with:
         ```
         const HEALTH_THRESHOLD_MS = 2 * 60 * 1000; // 2 minutes
         const now = Date.now();
         const lastExec = healthState.lastExecutionTime;
         const isHealthy = lastExec !== null && (now - lastExec.getTime()) < HEALTH_THRESHOLD_MS;
         const status = isHealthy ? "healthy" : "unhealthy";
         const statusCode = isHealthy ? 200 : 503;
         res.status(statusCode).json({
           status,
           service: "order-execution-keeper",
           uptime: Math.floor((now - healthState.startedAt.getTime()) / 1000),
           lastExecutionTime: lastExec?.toISOString() ?? null,
           oracleConnected: healthState.oracleConnected,
           executionCounts: healthState.executionCounts,
         });
         ```
       - Replace console.log in listen callback with logger.info

    5. Update `/Users/ken/Projects/0xM/order-execution-keeper-service/src/index.ts`:

       - Import `recordExecution`, `recordScanCycle`, `setOracleStatus` from `./utils/healthState.js`
       - Replace ALL console.log/warn/error calls with logger equivalents:
         - `console.log("[order-execution-keeper] starting")` → `logger.info("starting")`
         - `console.error("[order-execution-keeper] ...", error)` → `logger.error({ err: error }, "message")`
