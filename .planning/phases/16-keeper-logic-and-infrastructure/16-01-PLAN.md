Create `src/watcher.ts` that exports a `startWatcher` function accepting an `enqueue(key: Hex, type: OpType) => void` callback and returning an `unwatch` function.

Implementation:
1. Define `type OpType = "deposit" | "withdrawal" | "order"` and export it (executor.ts and poller.ts will import it).
2. Define `EVENT_MAP: Record<string, OpType>` mapping `DepositCreated` -> `"deposit"`, `WithdrawalCreated` -> `"withdrawal"`, `OrderCreated` -> `"order"`.
3. Create a WebSocket public client using `createPublicClient` with `webSocket(config.wsRpcUrl, { reconnect: { attempts: Infinity, delay: 1_000 } })` and `baseSepolia` chain.
4. Use `wsClient.watchContractEvent` with:
   - `address: config.eventEmitterAddress`
   - `abi: eventEmitterAbi`
   - `eventName: "EventLog1"`
   - `onLogs`: iterate logs, read `log.args.eventName` (non-indexed string in data) to look up in EVENT_MAP. If match found, extract `log.args.topic1` as the operation key (bytes32). Call `enqueue(key, opType)`.
   - `onError`: log at error level using pino child logger, do NOT crash -- viem WebSocket auto-reconnects.

CRITICAL: Use `log.args.eventName` (non-indexed string), NOT `log.args.eventNameHash` (indexed, returns keccak256 hash). See Pitfall 1 in 16-RESEARCH.md.

5. Create a pino child logger: `pino({ name: "watcher" })`.
6. Log at info level when watcher starts: `log.info("event watcher started")`.
7. Return the `unwatch` function from `watchContractEvent`.

Function signature:
```typescript

export function startWatcher(enqueue: (key: Hex, type: OpType) => void): () => void;
```

<task type="auto">
  <name>Task 3: Create executor.ts -- Sequential execution with dedup, retry, and token extraction</name>
  <files>order-execution-keeper-service/src/executor.ts</files>
  <action>
Create `src/executor.ts` that exports a `createExecutor` function. This is the core execution engine: dedup Set, FIFO queue, event-driven wake, token extraction, TX submission with manual nonce, and error classification.

Implementation:

**1. Shared state and types:**
```typescript
interface QueueItem { key: Hex; type: OpType; retries: number; }
```
- `queue: QueueItem[]` -- plain Array, push/shift
- `seen: Set<string>` -- bytes32 keys (lowercase), dedup. Keys stay forever per user decision.
- `shuttingDown: boolean` -- set by SIGTERM handler
- `wakeResolver: (() => void) | null` -- event-driven wake

**2. createExecutor function:**
Returns an object with: `{ enqueue, start, shutdown, getQueueLength, getSeenCount }`.

**3. enqueue(key: Hex, type: OpType):**
- Lowercase the key for consistent Set lookup
- If `seen.has(key)`, return silently (dedup)
- `seen.add(key)`, `queue.push({ key, type, retries: 0 })`
- Log at info level: `log.info({ key, type }, "enqueued")`
- Wake executor: if `wakeResolver` exists, call it and set to null

**4. waitForWork():**
- If `queue.length > 0`, return immediately
- Otherwise, return `new Promise<void>(resolve => { wakeResolver = resolve; })`

**5. start() -- the main executor loop:**
Runs `while (!shuttingDown)`:
- `await waitForWork()`
- If `shuttingDown` or queue empty, continue/break
- `const item = queue.shift()!`
- Try: `await executeOne(item)`
- Catch: handle with error classification (see step 7)

**6. executeOne(item: QueueItem):**
Create both clients at module level (not per-call):
- `publicClient` = `createPublicClient({ chain: baseSepolia, transport: http(config.rpcUrl) })`
- `walletClient` = `createWalletClient({ chain: baseSepolia, transport: http(config.rpcUrl), account: privateKeyToAccount(config.privateKey) })`

Per operation type, extract tokens and call the appropriate handler:

For deposits (EXEC-01):
- Read struct: `publicClient.readContract({ address: config.readerAddress, abi: readerAbi, functionName: "getDeposit", args: [config.dataStoreAddress, item.key] })`
- Check `deposit.addresses.account === ZERO_ADDRESS` -> skip (zeroed struct, already executed). Log at debug level.
- Read market: `publicClient.readContract({ address: config.readerAddress, abi: readerAbi, functionName: "getMarket", args: [config.dataStoreAddress, deposit.addresses.market] })`
- Extract tokens into a Set<Address>: always add `marketData.indexToken` if non-zero. Add `deposit.addresses.initialLongToken` if non-zero AND `deposit.numbers.initialLongTokenAmount > 0n`. Add `deposit.addresses.initialShortToken` if non-zero AND `deposit.numbers.initialShortTokenAmount > 0n`.
- Call `buildOracleParams([...tokenSet])`
- Submit TX: `executeDeposit` via handler

For withdrawals (EXEC-02):
- Same pattern but `getWithdrawal`, extract market's indexToken + longToken + shortToken (all if non-zero)
- Submit TX: `executeWithdrawal` via handler

For orders (EXEC-03):
- Same pattern but `getOrder`, extract `marketData.indexToken` + `order.addresses.initialCollateralToken` (if non-zero)
- Check `order.flags.isFrozen` -> skip if frozen. Log at info level.
- Submit TX: `executeOrder` via handler

**7. submitTx helper:**
```typescript
async function submitTx(handlerAddress: Address, abi: any, functionName: string, args: any[]): Promise<Hex>
```
- Get fresh nonce: `publicClient.getTransactionCount({ address: account.address, blockTag: "pending" })` -- per user decision, NOT viem's nonceManager
- Call `walletClient.writeContract({ address: handlerAddress, abi, functionName, args, gas: 2_500_000n, nonce })`
- Wait for receipt: `publicClient.waitForTransactionReceipt({ hash: txHash, timeout: 60_000 })`
- Log at info level: `{ key, type, txHash, blockNumber, gasUsed }`
- Return txHash

**8. Error classification (EXEC-05):**
`isPermanentError(err)`: Check error message for known selectors:
- `0x95b66fe9` (EmptyDeposit)
- `0xd84b8ee8` (OracleTimestampsAreLargerThanRequestExpirationTime)
- `0x05d102a2` (InvalidOracleProvider)
- `0x68b49e6c` (InvalidOracleProviderForToken)
- `execution reverted` (generic contract revert)

In catch block:
- If `isPermanentError(err)`: log at WARN level with key/type/error, do NOT retry. Key already in `seen` Set so it's permanently skipped.
- If transient AND `item.retries < 3`: increment retries, push back to queue, log at error level with attempt number. Apply exponential backoff: `await new Promise(r => setTimeout(r, 1000 * Math.pow(2, item.retries - 1)))` (1s, 2s, 4s) BEFORE re-enqueuing.
- If transient AND retries exhausted: log at error level with full stack trace, do NOT re-enqueue. Key stays in `seen`.

**9. shutdown():**
- Set `shuttingDown = true`
- Wake the executor (resolve wakeResolver) so the loop can exit
- Log at info level

**10. ZERO_ADDRESS constant:**
`const ZERO_ADDRESS = "0x0000000000000000000000000000000000000000" as Address;`

Import from:
- `viem`: createPublicClient, createWalletClient, http, type Hex, type Address
- `viem/chains`: baseSepolia
- `viem/accounts`: privateKeyToAccount
- `./config.js`: config
- `./abis.js`: readerAbi, depositHandlerAbi, withdrawalHandlerAbi, orderHandlerAbi
- `./oracle.js`: buildOracleParams
- `./watcher.js`: type OpType
- `pino`: default import
