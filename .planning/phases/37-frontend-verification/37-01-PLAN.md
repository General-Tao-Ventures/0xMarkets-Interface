  <action>
Create `e2e/verify-frontend-data.ts` that reads on-chain state and outputs structured verification results. The script must cover all four FE requirements in a single run.

**Structure the script with four verification sections:**

1. **Pool Verification (FE-01):** For each of the 6 markets in MARKETS, read:
   - POOL_AMOUNT from DataStore (USDC pool amount, using the hashString/poolAmountKey pattern from check-pool.ts)
   - GM token totalSupply (the market address IS the GM token -- read ERC20 totalSupply on the market address)
   - GM token balance of the test wallet (balanceOf on market address)
   - Output: market name, pool USDC amount, GM total supply, wallet GM balance

2. **Position Verification (FE-02):** Read getAccountPositions from SyntheticsReader (same pattern as check-positions.ts):
   - Use Reader ABI with getAccountPositions(DataStore, account, 0, 100)
   - For each position with sizeInUsd > 0: output market, isLong, sizeInUsd (formatted with 30 decimals), collateralAmount (formatted with 6 decimals), calculated leverage
   - Include the position key for cross-referencing

3. **Order Verification (FE-03):** Read getAccountOrders from SyntheticsReader (using syntheticsReaderAbi from abis.ts):
   - Use getAccountOrders(DataStore, account, 0, 100)
   - For each order: output orderType (0=MarketIncrease, 1=LimitIncrease, 2=MarketDecrease, etc.), market, sizeDeltaUsd, triggerPrice, isLong, isFrozen
   - Report total pending order count

4. **Token Balance Verification (FE-04):**
   - USDC balance: read balanceOf on USDC_ADDRESS for test wallet (6 decimals)
   - ETH balance: read getBalance for test wallet (18 decimals)
   - Output formatted balances

**Output format:** Use console.log with clear section headers and a final JSON summary object that can be parsed programmatically:
```
=== POOL VERIFICATION (FE-01) ===
WETH/USD: Pool USDC=12345.67, GM Supply=1000.00, Wallet GM=50.00
...

=== POSITION VERIFICATION (FE-02) ===
Found 2 positions:
  WBTC/USD LONG: Size=$35,020.00, Collateral=805.00 USDC, Leverage=43.5x
...

=== ORDER VERIFICATION (FE-03) ===
Found 0 pending orders
...

=== TOKEN BALANCE VERIFICATION (FE-04) ===
USDC: 1234.56
ETH: 0.0456
...

=== VERIFICATION SUMMARY ===
{ "pools": 6, "positions": 2, "orders": 0, "usdc": "1234.56", "eth": "0.0456", "status": "COMPLETE" }
```

**Important implementation details:**
- Import publicClient, CONTRACTS, MARKETS, USDC_ADDRESS, WETH_ADDRESS from ./config.js
- Import erc20Abi, syntheticsReaderAbi from ./abis.js
- Add a totalSupply entry to the erc20Abi usage (or define a minimal ABI inline for totalSupply)
- The DataStore getUint ABI is not in abis.ts -- define it inline (same as check-pool.ts does)
- The getAccountPositions Reader ABI is not in abis.ts -- define it inline (same as check-positions.ts does)
- Use `formatUnits` from viem for all number formatting
- Wrap each section in try/catch so one failure doesn't block others
- Exit with code 0 on success, 1 if any section throws
