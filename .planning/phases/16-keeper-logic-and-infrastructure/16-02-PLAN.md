Startup sequence (per user decision in CONTEXT.md):
1. Log config summary (same masked pattern as current index.ts)
2. `await startOracle()` -- waits for all 7 token prices
3. `const executor = createExecutor()` -- creates queue, dedup Set, executor loop
4. `await pollDataStore(executor.enqueue)` -- initial full DataStore scan FIRST (catches pre-existing pending ops)
5. `const unwatch = startWatcher(executor.enqueue)` -- start event watcher for NEW ops
6. `const pollIntervalId = setInterval(() => pollDataStore(executor.enqueue), 15_000)` -- 15s polling safety net
7. Start executor loop (non-blocking): `executor.start()` -- runs in background, do NOT await (it's an infinite loop)
8. Start health server:
   ```typescript
   const startTime = Date.now();
   const account = privateKeyToAccount(config.privateKey);
   startHealthServer(config.port, () => ({
     status: isOracleStale() ? "degraded" : "ok",
     uptime: Math.floor((Date.now() - startTime) / 1000),
     queueLength: executor.getQueueLength(),
     seenCount: executor.getSeenCount(),
     keeperAddress: account.address,
     oracleStale: isOracleStale(),
     cachedTokenCount: getCachedTokenCount(),
   }));
   ```

SIGTERM / SIGINT graceful shutdown (INFRA-03):
```typescript
let isShuttingDown = false;
function shutdown() {
  if (isShuttingDown) return;
  isShuttingDown = true;
  log.info("shutting down -- completing in-flight TX...");

  // Stop accepting new work
  unwatch(); // stop WebSocket event watcher
  clearInterval(pollIntervalId); // stop poller

  // Tell executor to finish current TX and exit
  executor.shutdown();

  // Give executor time to finish in-flight TX, then exit
  // The executor loop will exit naturally after shutdown() is called
  setTimeout(() => {
    log.info("shutdown complete");
    process.exit(0);
  }, 30_000); // 30s max wait for in-flight TX
}

process.on("SIGTERM", shutdown);
process.on("SIGINT", shutdown);
```

Main function wraps in try/catch with `log.fatal({ err })` and `process.exit(1)`.
