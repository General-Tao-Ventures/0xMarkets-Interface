<objective>
Switch the keeper to Flashblocks-enabled RPC for ~200ms transaction confirmations, tighten background oracle updates to 5s intervals with a 30s safety margin, and eliminate the synchronous updatePriceOnChain call from the normal execution path.

Purpose: These three changes together reduce per-execution latency from ~6-8s to under 1s by eliminating the two largest latency contributors: slow TX confirmations (2-4s via standard RPC) and synchronous oracle price updates (2-4s blocking per token).

Output: Modified config, client, oracle, and executor files in order-execution-keeper-service; updated .env.production.example.
</objective>

    Replace the entire `// Update Lazer prices on-chain for entitled tokens` block (the `if (lazerTokens.length > 0)` block, lines ~236-280) with a new block that:
    1. For each Lazer token, calls `isStoredPriceFresh(token)`.
    2. If fresh: keeps the token in lazerTokens (no action needed — background updater handled it).
    3. If NOT fresh: logs a WARNING (`"stored price unexpectedly stale — background updater may be behind, falling back to Hermes"`), moves the token from lazerTokens to hermesTokens. Does NOT call `updatePriceOnChain()`.
    4. The key behavior change: **no synchronous `updatePriceOnChain()` call ever happens in the execution hot path**. The background updater (running every 5s) is the sole source of on-chain price freshness. If it fails, the execution gracefully degrades to Hermes rather than blocking for 2-4s.

    **CRITICAL:** Preserve the existing nonce coordination pattern in `drainQueue()` (index.ts). Background updates are disabled during execution via `disableBackgroundUpdates()` / `enableBackgroundUpdates()`. This pattern MUST remain even though we're removing the sync path — it prevents nonce collisions between background updates and execution TXs.

    **CRITICAL:** Do NOT remove the `isStoredPriceFresh()` method itself — it's still called to decide whether to use Lazer or fall back to Hermes. Only remove the `updatePriceOnChain()` call that was the synchronous fallback when prices were stale.
