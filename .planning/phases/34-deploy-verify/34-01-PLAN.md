**docker-compose.yml** -- Add `WS_RPC_URL: ${WS_RPC_URL}` to the `verifier` service environment section, right after `RPC_URL`:

```yaml
environment:
  DATABASE_URL: postgresql://verifier:verifier@postgres:5432/data_verification
  RPC_URL: ${RPC_URL}
  WS_RPC_URL: ${WS_RPC_URL}
  PYTH_PRO_ACCESS_TOKEN: ${PYTH_PRO_ACCESS_TOKEN}
  CHAIN_ID: 84532
```

This passes the host `.env` value into the container. Without this, the container will crash on startup because `config.ts` calls `required("WS_RPC_URL")`.

**.env.example** -- Add the WS_RPC_URL entry after RPC_URL:

```
DATABASE_URL=postgresql://verifier:verifier@localhost:5433/data_verification
RPC_URL=https://sepolia.base.org
WS_RPC_URL=wss://base-sepolia-rpc.publicnode.com
PYTH_PRO_ACCESS_TOKEN=your_pyth_pro_token
CHAIN_ID=84532
PORT=37019
```

Note: The example WSS URL `wss://base-sepolia-rpc.publicnode.com` is a free public endpoint. The actual production value may differ depending on the RPC provider.

**index.ts** -- Enhance the health endpoint to report `eventsPerMinute`. The DEPLOY-03 requirement specifies "events/min" in addition to last block and events count.

Compute the rate from the existing `indexedEventCount` and `startTime`:

```typescript
app.get("/health", (_req, res) => {
  const uptimeSeconds = Math.floor((Date.now() - startTime) / 1000);
  const uptimeMinutes = uptimeSeconds / 60;
  const eventsPerMinute = uptimeMinutes > 0
    ? Math.round(getIndexedEventCount() / uptimeMinutes * 100) / 100
    : 0;

  res.json({
    status: "ok",
    lastBlock: Number(getLastProcessedBlock()),
    lastPriceTick: getLastPriceTickTimestamp()?.toISOString() ?? null,
    lastIndexedBlock: Number(getLastIndexedBlock()),
    indexedEvents: getIndexedEventCount(),
    eventsPerMinute,
    uptime: uptimeSeconds,
  });
});
```

This gives a simple rolling average since startup. No complex windowed rate tracking needed -- the rate will stabilize within a few minutes of running.
