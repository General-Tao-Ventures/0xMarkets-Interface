## CRITICAL: SyntheticsReader ABI is stale

**Error:** `Multicall request failed: usePositionsData Error: Response error reader: positions: Bytes value "33,80,74,125,83,219,108,27,176" is not a valid boolean.`

**Root cause:** The deployed `SyntheticsReader` contract returns `PositionFees` structs with `secondaryFeeReceiver` fields that the frontend ABI (`sdk/src/abis/SyntheticsReader.json`) does NOT have:

1. `PositionFees` struct missing: `positionFeeSecondaryReceiverFactor`, `secondaryFeeReceiverAmount`
2. `PositionBorrowingFees` struct missing: `borrowingFeeSecondaryReceiverFactor`, `borrowingFeeAmountForSecondaryReceiver`
3. `PositionLiquidationFees` struct missing: `liquidationFeeSecondaryReceiverFactor`, `liquidationFeeAmountForSecondaryReceiver`

The extra fields cause the ABI decoder to misalign — a uint256 gets decoded at a bool offset.

**Fix approach:** Regenerate the ABI from the deployed SyntheticsReader at `0x1e6Ca8042e7BC258BBbA35C5C86F013b4eceC03C` on Base Sepolia, OR manually add the missing fields to `sdk/src/abis/SyntheticsReader.json`. The contract source is at `/Users/ken/Projects/0xM/0xmarkets_contract/contracts/pricing/PositionPricingUtils.sol`.

**Fields to add (from contract source):**
- In `PositionFees`: add `positionFeeSecondaryReceiverFactor` (uint256) and `secondaryFeeReceiverAmount` (uint256) after `positionFeeReceiverFactor` and `feeReceiverAmount` respectively
- In `PositionBorrowingFees`: add `borrowingFeeSecondaryReceiverFactor` (uint256) and `borrowingFeeAmountForSecondaryReceiver` (uint256) after `borrowingFeeReceiverFactor` and `borrowingFeeAmountForFeeReceiver` respectively
- In `PositionLiquidationFees`: add `liquidationFeeSecondaryReceiverFactor` (uint256) and `liquidationFeeAmountForSecondaryReceiver` (uint256) after existing fields

Also update `src/typechain-types/SyntheticsReader.ts` and `src/typechain-types/factories/SyntheticsReader__factory.ts` to match.
