    4. `broadcast(msg: string): void` — Iterates `wss.clients`, skips non-OPEN clients, skips clients with `bufferedAmount > 64 * 1024`, sends pre-serialized msg string.

    5. `stopWsBroadcast(): void` — Clears heartbeat and candle intervals, closes WebSocketServer.

    6. Export `getWsClientCount(): number` — Returns `wss?.clients.size ?? 0` for health endpoint.
