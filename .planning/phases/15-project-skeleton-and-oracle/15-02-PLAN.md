**Constants:**

```typescript
interface CacheEntry {
  rawUpdate: Hex;      // Binary EVM data for on-chain submission
  cachedAt: number;    // Date.now() when received
  feedId: number;
}
```

- WETH: 0x4200000000000000000000000000000000000006, feedId: 2

**Module-level state:**
- `cache = new Map<string, CacheEntry>()` (key: lowercase token address)
- `isStale = false`
- `disconnectedAt: number | null = null`

**getLatestUpdate(token: Address): CacheEntry | undefined** (not exported -- internal)
- Look up by `token.toLowerCase()`
- TTL check: if `Date.now() - entry.cachedAt > CACHE_TTL_MS`, delete entry and return undefined (ORCL-03)
- Return entry if valid, undefined if not found or expired

**handleMessage(message: JsonOrBinaryResponse): void** (not exported -- internal)
- If `message.type !== "binary"`, return (skip JSON messages)
- Extract binaryResponse: `message.value` -- type as any needed since SDK types may not perfectly match
- If no `evm` property, return
- Convert to hex: `"0x" + Buffer.from(binaryResponse.evm).toString("hex")` as Hex
- Cache for ALL feeds: each binary message contains all subscribed feed data, so set all 7 cache entries with the same rawUpdate and current Date.now()
- If `isStale` was true, log recovery and reset: `isStale = false`, `disconnectedAt = null`

**buildOracleParams(tokens: Address[])** (exported) -- ORCL-02:
Returns `{ tokens: Address[], providers: Address[], data: Hex[] }`
- For each token, call getLatestUpdate
- If any token has no cached price, throw Error with the missing token address
- Provider is ALWAYS `config.pythLazerFeedProviderAddress` (same for all tokens -- no per-token routing)
- Return arrays of tokens, providers (all same address), and raw binary data

**getCachedTokenCount(): number** (exported) -- returns cache.size
**isOracleStale(): boolean** (exported) -- returns isStale flag

**startOracle(): Promise<void>** (exported):
1. Create pino logger: `pino({ name: "oracle" })`
2. Create client: `await PythLazerClient.create({ token: config.pythProAccessToken, webSocketPoolConfig: { numConnections: 1, onError: (err) => log.error({ err }, "ws error"), rwsConfig: { heartbeatTimeoutDurationMs: 5000, maxRetryDelayMs: 30000, logAfterRetryCount: 10 } } })`
3. Add message listener: `client.addMessageListener(handleMessage)`
4. Add all-connections-down listener: sets `disconnectedAt = Date.now()`, `isStale = true`, logs error "all connections down -- oracle stale"
5. Subscribe: `{ type: "subscribe", subscriptionId: 1, priceFeedIds: FEEDS.map(f => f.feedId), properties: ["price"], formats: ["evm"], deliveryFormat: "binary", channel: "fixed_rate@200ms", parsed: false }`
6. Startup gate: poll every 500ms until cache.size >= FEEDS.length. If 30s timeout exceeded, log FATAL with which tokens are missing and `process.exit(1)`
7. Start background interval (every 10s): if `disconnectedAt && Date.now() - disconnectedAt > STALE_THRESHOLD_MS`, log FATAL "oracle disconnected for >60s -- check PYTH_PRO_ACCESS_TOKEN"
8. Log state transitions only (connect, disconnect, stale, recovery) -- NOT individual price updates per CONTEXT.md decision

**SDK import:** `import { PythLazerClient } from "@pythnetwork/pyth-lazer-sdk"`. The types `JsonOrBinaryResponse` and `BinaryResponse` may need to be imported or handled via `any` depending on what v5.2.0 exports. Check the actual exports and use what's available. If types aren't exported, use the callback parameter type from `addMessageListener`.

**CRITICAL: Use `console` as SDK logger (not pino).** The SDK accepts a `Logger` interface matching console. Passing pino directly may not match the interface. SDK-level events are handled through the message listener and connection-down listener anyway.

```typescript
import { config } from "./config.js";
import { startOracle, getCachedTokenCount, FEEDS } from "./oracle.js";
import pino from "pino";

const log = pino({ name: "order-keeper" });

async function main() {
  // Log startup config summary (per CONTEXT.md -- mask RPC credentials)
  log.info({
    chainId: config.chainId,
    rpcUrl: config.rpcUrl.replace(/\/\/.*@/, "//<masked>@"),
    wsRpcUrl: config.wsRpcUrl.replace(/\/\/.*@/, "//<masked>@"),
    oracleProvider: config.pythLazerFeedProviderAddress,
    port: config.port,
    tokenCount: FEEDS.length,
  }, "starting order-execution-keeper");

  // Start oracle -- waits for all 7 token prices (30s timeout)
  await startOracle();

  log.info({ cachedTokens: getCachedTokenCount() }, "oracle cache populated -- ready");

  // Phase 16 adds: event watcher, poller, executor, health endpoint
  // For now, keep the process alive to observe oracle behavior
  process.on("SIGINT", () => {
    log.info("shutting down");
    process.exit(0);
  });
  process.on("SIGTERM", () => {
    log.info("shutting down");
    process.exit(0);
  });
}

main().catch((err) => {
  log.fatal({ err }, "startup failed");
  process.exit(1);
});
```
