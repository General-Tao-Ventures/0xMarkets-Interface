  <action>
    1. In `httpServer.ts`, add manual CORS middleware BEFORE the route registration (`app.use("/api", routes)`). Do NOT install the `cors` npm package — use manual headers per research recommendation:
       ```typescript
       app.use((_req, res, next) => {
         res.setHeader("Access-Control-Allow-Origin", process.env.CORS_ALLOWED_ORIGINS || "*");
         res.setHeader("Access-Control-Allow-Methods", "GET");
         next();
       });
       ```
       Use `"*"` as default — this is testnet only, no sensitive data. Place this AFTER `app.use(express.json())` and BEFORE `app.use("/api", routes)`.

    2. Create `src/server/controllers/depositController.ts`:
       - Import `Request, Response` from "express" and `getOrCreatePrismaClient` from `../../core/store.js`
       - Export async function `getDepositStatus(req: Request, res: Response)`
       - Extract `key` from `req.params`
       - Query `prisma.depositRequest.findUnique({ where: { requestKey: key }, select: { requestKey: true, account: true, status: true, errorReason: true, retryCount: true, createdAt: true, updatedAt: true } })`
       - If not found, return `res.status(404).json({ error: "Deposit not found" })`
       - On success, return `res.json({ key: deposit.requestKey, status: deposit.status, errorReason: deposit.errorReason ?? null, retryCount: deposit.retryCount, createdAt: deposit.createdAt.toISOString() })`
       - Wrap in try/catch, return 500 on error with `{ error: "Internal server error" }`
       - Note: `deposit.status` is one of "PENDING" | "EXECUTED" | "FAILED" | "CANCELLED" (RequestStatus enum from Prisma schema)

    3. In `routes/index.ts`:
       - Import `getDepositStatus` from `../controllers/depositController.js` (note the .js extension for ESM compatibility — same pattern as healthController import)
       - Add route: `router.get("/deposits/:key", getDepositStatus)`
       - Place AFTER the existing `/health` route
