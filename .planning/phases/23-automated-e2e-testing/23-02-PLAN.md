  <name>Task 1: Implement withdrawal and order E2E test scripts</name>
  <files>e2e/test-withdrawals.ts, e2e/test-orders.ts</files>
  <action>
Create both test scripts following the same structure as test-deposits.ts from Plan 01.

**e2e/test-withdrawals.ts:**

Flow per market:
1. Check market token balance (the market address IS the GM token ERC20)
2. If balance is 0, log SKIP with note "No market tokens -- run deposits first"
3. Withdraw half of market token balance (or all if small)
4. Approve market token against Router (SyntheticsRouter) if needed
5. Build multicall: `[sendWnt(withdrawalVault, execFee), sendTokens(marketToken, withdrawalVault, amount), createWithdrawal(params)]`
6. Submit tx, extract operation key
7. `waitForExecution(... , "Withdrawal", 60000)`
8. Record PASS/FAIL

Withdrawal-specific params:
- receiver: wallet address
- market: market address
- minLongTokenAmount: 0, minShortTokenAmount: 0
- callbackContract: zeroAddress, callbackGasLimit: 0
- shouldUnwrapNativeToken: false
- executionFee: 0.001 ETH
- uiFeeReceiver: zeroAddress
- longTokenSwapPath: [], shortTokenSwapPath: []

IMPORTANT: The token sent to WithdrawalVault is the MARKET TOKEN (the market address itself, which is an ERC20 GM token), NOT USDC. The approval must be against Router (SyntheticsRouter: 0x33153255bed0219b571483e6a0801Fa0B916f7D7), not ExchangeRouter.

**e2e/test-orders.ts:**

Flow per market:
1. Build MarketIncrease long order: 5 USDC collateral, $10 size
2. multicall: `[sendWnt(orderVault, execFee), sendTokens(usdc, orderVault, 5e6), createOrder(params)]`
3. Submit tx, extract operation key
4. `waitForExecution(... , "Order", 60000)`
5. Record PASS/FAIL

Order-specific params:
- addresses: { receiver: wallet, cancellationReceiver: zeroAddress, uiFeeReceiver: zeroAddress, callbackContract: zeroAddress, market: marketAddress, initialCollateralToken: USDC, swapPath: [] }
- numbers: { sizeDeltaUsd: 10n * 10n**30n (10 USD with 30 decimals), triggerPrice: 0, acceptablePrice: maxUint256, executionFee, callbackGasLimit: 0, minOutputAmount: 0, initialCollateralDeltaAmount: 0, validFromTime: 0 }
- orderType: 2 (MarketIncrease)
- isLong: true
- shouldUnwrapNativeToken: false
- decreasePositionSwapType: 0
- autoCancel: false
- referralCode: zeroHash (bytes32 zero)

**Both scripts:**
- Same output format as test-deposits.ts (header, per-market detail, results summary)
- Same `MARKET=X` env var filter for single-market testing
- Same 3-second delay between markets
- Same error handling (catch revert, catch timeout)
- Exit code: 0 = all pass, 1 = any fail

**NOTE on test ordering:** Withdrawals REQUIRE prior deposits (need GM tokens). Orders are independent. When running the full suite (`test:all`), the order is deposits -> withdrawals -> orders, which ensures withdrawals have tokens to withdraw.
