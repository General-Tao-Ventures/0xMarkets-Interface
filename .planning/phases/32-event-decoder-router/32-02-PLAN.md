**insertBuilder.ts** — Create a generic, data-driven insert builder. The goal: each handler defines WHAT to extract, the builder generates HOW to insert.

```typescript
import type { DecodedEventData, LogMeta } from './types.js';
import type { Client } from 'pg';

// Column extraction source — which Map in DecodedEventData to pull from
export type ColumnSource =
  | { from: 'address'; key: string }
  | { from: 'addressArray'; key: string }
  | { from: 'uint'; key: string }
  | { from: 'uintArray'; key: string }
  | { from: 'int'; key: string }
  | { from: 'intArray'; key: string }
  | { from: 'bool'; key: string }
  | { from: 'bytes32'; key: string }
  | { from: 'bytes'; key: string }
  | { from: 'string'; key: string }
  | { from: 'stringArray'; key: string };

export interface ColumnSpec {
  column: string;        // SQL column name (snake_case)
  source: ColumnSource;  // where to extract from DecodedEventData
  nullable?: boolean;    // if true, missing value -> NULL instead of error
}

export interface EventTableSpec {
  schema: string;        // PG schema (e.g. 'orders')
  table: string;         // table name (e.g. 'created')
  columns: ColumnSpec[]; // columns to extract (beyond the common 5)
}

export type EventHandler = (client: Client, data: DecodedEventData, meta: LogMeta) => Promise<void>;
```

The `buildHandler(spec: EventTableSpec): EventHandler` function:
1. Returns an async function that:
   a. Starts with the 5 common columns: `block_number` (meta.blockNumber), `log_index` (meta.logIndex), `tx_hash` (meta.transactionHash), `block_timestamp` (new Date(Number(meta.blockTimestamp) * 1000)), `created_at` (omitted — uses DEFAULT NOW())
   b. For each ColumnSpec, extracts the value from the correct Map in DecodedEventData
   c. For `uint` and `int` sources, converts bigint to string for NUMERIC columns (pg driver needs string for NUMERIC)
   d. For `addressArray`/`uintArray`/`intArray`/`boolArray`/`stringArray` sources, passes the array directly (pg driver handles TEXT[] and NUMERIC[] arrays)
   e. For nullable columns: if value is undefined, inserts NULL
   f. For non-nullable columns: if value is undefined, throws an error (data integrity)
   g. Builds parameterized INSERT: `INSERT INTO schema.table (col1, col2, ...) VALUES ($1, $2, ...) ON CONFLICT (block_number, log_index) DO NOTHING`
   h. Uses ON CONFLICT DO NOTHING for idempotency (duplicate log from re-processing)
   i. Executes via `client.query(sql, params)`

**IMPORTANT for oracle.price_update**: The `timestamp` column is a PostgreSQL reserved word and is quoted in the SQL schema as `"timestamp"`. The insert builder must quote this column name. Add a `quoted?: boolean` flag to ColumnSpec, or just always quote all column names with double quotes in the generated SQL (safest approach — quote all column names).

**router.ts** — The central dispatch module.

1. Import all 9 handler maps from `./handlers/*.js`
2. Merge them into a single `Map<string, EventHandler>` (or plain object)
3. Export `routeEvent(client: Client, data: DecodedEventData, meta: LogMeta): Promise<void>`:
   a. Look up `data.eventName` in the handler map
   b. If found: call the handler with (client, data, meta)
   c. If not found: log at WARN level with `{ eventName: data.eventName, blockNumber: meta.blockNumber.toString() }` and return (no throw, no crash)
