- `0x81B38574Fd6e22abA37b7AC1AaDd28277E0e87A3` — the docs address — also has NO code deployed.

The order-execution-keeper works fine because it passes oracle price data INLINE during execution transactions (doesn't need `getStoredPrice`). The keeper-service scanner is the only consumer of `getStoredPrice`.

Option 2 is likely fastest — the scanner already runs in keeper-service which has WebSocket oracle infrastructure.
