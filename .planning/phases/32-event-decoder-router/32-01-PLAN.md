Export `decodeEventLog(topics: string[], data: string, isEventLog2: boolean): DecodedEventData`.

The function:
1. Calls `decodeAbiParameters(EVENT_LOG_DATA_PARAMS, data as Hex)` — viem returns named fields when AbiParameter has `name`
2. Extracts `msgSender`, `eventName`, `eventData` from the decoded result
3. Converts each items group into a `Map<string, T>` using helper functions `extractItems` and `extractArrayItems` (same pattern as squid)
4. Sets `topic1 = topics[2]` if present (same for both EventLog1 and EventLog2)
5. Returns the `DecodedEventData` object

IMPORTANT: viem returns bigint natively for uint256/int256 (no need for the squid's `toBigInt` conversion). viem returns addresses as lowercase `0x` hex strings. These are both correct for our use case.

Also export helper getter functions matching the squid's pattern: `getAddress`, `getUint`, `getInt`, `getBool`, `getBytes32`, `getString`, `getAddressArray`, `getUintArray`, `getBoolArray`.
