    - Test: onclose schedules reconnect with exponential backoff (1s, 2s, 4s... capped at 30s)
    - Test: reconnect resets attempt counter on successful connection
    - Test: disconnect() closes socket and sets state to "disconnected" without reconnect
    - Test: isNewerThan(incomingTs, currentTs) returns true only when incoming > current (timestamp gating utility)

  <action>
Create `src/lib/keeperWebSocket/types.ts` with:
- `ConnectionState = "connected" | "reconnecting" | "disconnected"`
- `TickerData` matching the TickersResponse item shape (minPrice, maxPrice, oracleDecimals, tokenSymbol, tokenAddress, updatedAt)
- `CandleData` with tokenSymbol, open, high, low, close, minuteTs (all numbers except tokenSymbol)
- `TickerMessage = { type: "ticker"; data: TickerData[] }`
- `CandleMessage = { type: "candle"; data: CandleData[] }`
- `KeeperWsMessage = TickerMessage | CandleMessage`
- `isNewerThan(incomingTs: number, currentTs: number): boolean` -- returns `incomingTs > currentTs`

Create `src/lib/keeperWebSocket/KeeperWebSocketManager.ts`:
- Singleton class with `connect()`, `disconnect()`, `getState()`, `on(event, handler)`, `off(event, handler)` methods
- Events: "ticker", "candle", "stateChange"
- `connect()`: Create `new WebSocket(url)`, wire onopen (state -> connected, reset attempts, emit stateChange), onmessage (JSON.parse, emit by type), onclose (call scheduleReconnect), onerror (no-op, onclose handles it)
- `scheduleReconnect()`: state -> reconnecting, emit stateChange, delay = min(1000 * 2^attempts, 30000), attempts++, setTimeout -> connect()
- `disconnect()`: set a `manualDisconnect` flag, close socket, state -> disconnected, emit stateChange. `scheduleReconnect` checks this flag and returns early if set.
- Constructor takes `url: string`. Use `getKeeperWebSocketUrl()` helper that returns `ws://142.93.203.222:37017` when `isLocal()` or `wss://keeper.0xmarkets.io` otherwise.
- Do NOT use Socket.IO or any library -- browser native WebSocket only.

Create unit tests using Vitest. Mock WebSocket using a minimal class mock (happy-dom may or may not provide it -- create a manual mock with onopen/onclose/onmessage/onerror/close/readyState). Test all behaviors listed above. Use `vi.useFakeTimers()` for reconnect delay tests.
