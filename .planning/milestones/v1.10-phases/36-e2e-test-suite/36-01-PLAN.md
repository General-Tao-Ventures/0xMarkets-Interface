**test-orders.ts changes:**

The existing `testOrder()` function only opens a MarketIncrease long position. It needs to also close the position with a MarketDecrease order. Modify `testOrder()` as follows:

1. After the MarketIncrease order is executed successfully (line ~143, after `executionResult.status === "executed"`), add a MarketDecrease close step:
   - Wait 3s for state to settle (same pattern as test-trigger-orders.ts)
   - Create a MarketDecrease order (orderType: 4) with:
     - Same market address
     - `sizeDeltaUsd`: same as the open ($10 in 30-decimal format = `10n * 10n ** 30n`) to close the full position
     - `initialCollateralDeltaAmount`: same collateral amount (5_000_000n) to withdraw all collateral
     - `acceptablePrice`: `0n` for long decrease (accept any price downward)
     - `triggerPrice`: `0n` (market order, not trigger)
     - No collateral transfer needed for decrease orders (collateral comes from position)
   - The multicall for MarketDecrease should only contain: sendWnt (execution fee to OrderVault) + createOrder. Do NOT send tokens for decrease orders.
   - Wait for keeper execution with 60s timeout
   - If close succeeds, log "Position closed" and return PASS
   - If close fails (cancelled/timeout), return FAIL with "Position opened but close failed: {reason}"

2. Update the main() function: After all test results, check USDC balance again and log the difference to confirm collateral was returned.

**test-liquidation.ts changes:**

The existing script targets WETH/USD which is at 100% reserve capacity. Update it:

1. Change `TARGET_MARKET` from `"WETH/USD"` to attempt multiple markets in priority order: `["WBTC/USD", "EUR/USD", "GBP/USD"]`. Skip WETH/USD (100% reserve) and JPY/USD (Pyth Lazer data gap) and GOLD/USD (recording 0 prices).

2. Restructure main() to try each target market. For each market:
   - Try each direction (long/short) and size tier (same existing logic)
   - If a position is created successfully, proceed to wait for liquidation

3. After a position is created successfully, add a liquidation wait loop:
   - Log the position key and "Waiting for keeper-service to detect and liquidate..."
   - Poll for the position's sizeInUsd using `Reader.getPosition` every 10s for up to 5 minutes
   - If sizeInUsd becomes 0, the position was liquidated -- log "LIQUIDATED" and exit 0
   - If still open after 5 minutes, log a warning but still exit 0 with a note that the position was created (manual verification needed since keeper-service liquidation scanner timing varies)

4. Make the script produce TestResult-compatible output by using formatResults at the end.

**Important constraints:**
- All markets use USDC as both long and short token (from config)
- MarketDecrease orderType = 4 (not 2 which is MarketIncrease)
- For decrease orders: do NOT send collateral tokens to OrderVault, only send execution fee (ETH via sendWnt)
- Use `decreasePositionSwapType: 0` (no swap needed since collateral is USDC)

     { name: "Deposits", file: "test-deposits.ts", env: { MARKET: "WETH/USD" } },

     { name: "Market Orders", file: "test-orders.ts", env: { MARKET: "WETH/USD" } },
