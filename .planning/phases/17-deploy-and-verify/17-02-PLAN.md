Human verifies that a deposit submitted via the frontend is detected and executed by the deployed keeper.

Steps:
1. Open the frontend at https://app.0xmarkets.io (or localhost if running locally)
2. Navigate to the Pools page and select any market (e.g., ETH/USD)
3. Click "Buy GM" and submit a deposit with a small amount of mUSDC
4. After the deposit transaction confirms on-chain, watch the keeper logs:
```bash
ssh root@142.93.203.222 'cd /opt/0xmarkets && docker compose logs --tail 20 -f order-execution-keeper'
```

   - `"enqueued"` log with type "deposit" and the deposit key
   - `"executing"` log with the deposit key
   - `"tx confirmed"` log with transaction hash and status "success"
6. In the frontend, verify the user's GM token balance increased (deposit executed successfully)

**If deposit doesn't execute within 30 seconds:**
- Check logs for errors: `docker compose logs --tail 50 order-execution-keeper`
- If "oracle stale" errors: Pyth Lazer may have disconnected. Check `curl http://142.93.203.222:37018/health` for `oracleStale: true`
- If "execution reverted": Check the revert reason in logs. Could be insufficient gas or contract state issue.
