<decisions_made>
- **WebSocket 4→1**: SDK dedup with 4 connections was dropping ALL binary messages. Order-execution-keeper uses 1 connection and works fine. Root cause confirmed: "Dropping duplicate message" flood with no data reaching handler.
- **Buffer.from()**: Pyth SDK returns Uint8Array for evm data, not Node.js Buffer. Uint8Array.toString('hex') does NOT produce hex — it calls Object.toString(). Must wrap with Buffer.from() first.
- **Executor confirmed passing real Lazer data**: Gas estimation error is PositionShouldNotBeLiquidated (0xee919dd9), not an oracle/verifyUpdate error. This proves Oracle.setPrices succeeds with the Lazer bytes.
- **Two paths forward**: PATH A = fix scanner ABI for long-term correctness. PATH B = create deep position for quick pipeline proof. Recommend PATH B first, PATH A in Phase 26 hardening.
</decisions_made>
