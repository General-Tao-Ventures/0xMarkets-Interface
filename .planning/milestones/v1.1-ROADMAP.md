# Milestone v1.1: Full Trading Experience

**Status:** SHIPPED 2026-02-22
**Phases:** 4-6
**Total Plans:** 8

## Overview

Enable the full trading loop — open positions, manage orders, and withdraw liquidity across all 6 markets (ETH, BTC, EUR, GBP, GOLD, JPY) on Base Sepolia.

## Phases

### Phase 4: Stable Foundation

**Goal**: Trade page loads without crashes and all 6 markets are fully configured for trading operations
**Depends on**: Phase 3 (v1.0 complete)
**Plans**: 2 plans

Plans:
- [x] 04-01: Frontend defensive guards — BigInt division by zero, WebSocket spam suppression, metrics endpoint
- [x] 04-02: On-chain market configuration for all 6 Base Sepolia markets

### Phase 5: Liquidity & Swaps

**Goal**: Users can withdraw liquidity from pools and view pool statistics, completing the liquidity lifecycle
**Depends on**: Phase 4
**Plans**: 2 plans

Plans:
- [x] 05-01: Sell GM flow — action buttons, withdrawal notifications with elapsed time, cancel support
- [x] 05-02: Pool stats — All Pools / My Pools tabs, utilization, fees earned, and PnL display

**Note:** SWAP-01 (token swaps) was explicitly deferred by user — "we don't need the swap route, we just want long and short"

### Phase 6: Position Management

**Goal**: Users can open, manage, and close leveraged positions with all order types across all 6 markets
**Depends on**: Phase 5
**Plans**: 4 plans

Plans:
- [x] 06-01: Market order submission and position display (end-to-end)
- [x] 06-02: Close positions (full and partial) via PositionSeller
- [x] 06-03: Limit orders and SL/TP order attachment with price shortcuts
- [x] 06-04: Human verification of all position management flows

## Milestone Summary

**Key Decisions:**
- Zero divisor returns 0n with console.warn (not throw) — allows page to load
- minCollateralFactor === 0n shows "Market unavailable" — semantic fix at validation layer
- Express loading state does not block trade/close buttons — awaits on submit, falls back
- Limit price shortcuts use BigInt basis-point math to avoid float precision errors
- SL shortcuts [-10%, -5%], TP shortcuts [+5%, +10%] from mark price
- SWAP-01 deferred — user prioritized trading over swaps

**Issues Resolved:**
- Division by zero crash on trade page (zero market config values)
- WebSocket CLOSING state spam
- Metrics 404/500 console noise
- PythLazerFeedProvider address mismatch in keeper
- Order executor passing market token instead of index token
- DataStore oracle providers pointing to old provider address
- Frontend BigInt crash (pendingImpactAmount missing from contract struct)

**Issues Deferred:**
- SWAP-01: Token swaps using pool liquidity (deferred to future milestone)
- 17 pre-existing failing SDK test files (unrelated to v1.1 changes)
- Pre-existing TypeScript error in useOrders.ts (OrderInfoStructOutput export mismatch)

**Technical Debt Incurred:**
- pendingImpactAmount defaulted to 0n — contract doesn't have this field, may need proper removal
- REQUEST_EXPIRATION_TIME increased to 3600s for testnet (should be configurable per environment)
- Cloud keepers need ABI + config updates to match local fixes
