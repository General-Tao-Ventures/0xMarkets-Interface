  <name>Task 1: Write the automated audit verification script</name>
  <files>0xmarkets_contract/scripts/auditAddresses.ts</files>
  <action>
Create `0xmarkets_contract/scripts/auditAddresses.ts` — a Hardhat script that:

1. **Reads on-chain market data** using `Reader.getMarkets(dataStore, 0, 100)`:
   - For each market: marketToken, indexToken, longToken, shortToken
   - Validate each market exists (non-zero address)

2. **Reads on-chain token asset addresses** from DataStore for synthetic/asset tokens:
   - EUR, GBP, GOLD, JPY asset addresses via `dataStore.getAddress(keccak256(abi.encode("ASSET_TOKEN", tokenSymbol)))`
   - Use the existing `keys.assetTokenKey(symbol)` utility from `../utils/keys`

3. **Reads on-chain market parameters** for each market via DataStore:
   - Reserve factor: `keys.reserveFactorKey(market, isLong)` — must be non-zero
   - Open interest cap: `keys.openInterestReserveFactorKey(market, isLong)` — must be non-zero
   - Max pool amount: `keys.maxPoolAmountKey(market, token)` — must be non-zero
   - Market enabled: check `keys.isMarketDisabled(market)` is false
   - Use `dataStore.getUint(key)` and `dataStore.getBool(key)` accordingly

4. **Reads on-chain oracle config** for each market's index token:
   - Oracle provider address via DataStore: `keys.oracleProviderForTokenKey(token)`
   - Compare against PythLazerFeedProvider addresses in keeper `.env` files

5. **Compares on-chain data against config files** by reading local filesystem:
   - Read and parse: `../../../0xMarkets-Interface/sdk/src/configs/markets.ts` (extract market addresses)
   - Read and parse: `../../../0xMarkets-Interface/sdk/src/configs/contracts.ts` (infrastructure addresses)
   - Read and parse: `../../../keeper-service/src/config/tokens.ts` (token addresses)
   - Read and parse: `../../../order-execution-keeper-service/.env` (contract addresses)
   - Read and parse: `../../../keeper-service/.env` (contract addresses)
   - Read and parse: `../../../0xMarkets-squid/src/processor.ts` (EventEmitter address)
   - For each config file, extract addresses via regex (not import — these are cross-repo files)

6. **Outputs structured results** to console:
   - Section per service: "Interface SDK", "Order Keeper", "Keeper Service", "Squid", "Contracts Repo"
   - For each address: `MATCH` or `MISMATCH (config: X, on-chain: Y)`
   - Summary: total checks, matches, mismatches
   - For market parameters: `OK (value: X)` or `MISSING/ZERO`

The script should be runnable via: `npx hardhat run scripts/auditAddresses.ts --network baseSepolia`

Reference existing `check-markets.ts` for the pattern of getting Reader/DataStore contracts. Use `fs.readFileSync` to read cross-repo config files for comparison. Use path.resolve(__dirname, '..', '..', '..', 'service-name') for paths.

IMPORTANT: The DataStore key encoding must use `ethers.utils.keccak256(ethers.utils.defaultAbiCoder.encode(...))` to match Solidity's `keccak256(abi.encode(...))`. Reference `utils/keys.ts` in the contracts repo for the exact key construction patterns — do NOT use `encodePacked` (produces different hashes, see project memory pitfall).
