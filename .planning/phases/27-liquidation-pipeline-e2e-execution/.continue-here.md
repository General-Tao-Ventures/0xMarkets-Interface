<blockers>

- **Price push failing for WETH/WBTC/USDC**: Error `Missing or invalid parameters` from viem writeContract. This may be because the walletClient Proxy in contract.ts doesn't properly support writeContract with all parameters, OR the `chain` property on the proxy returns incorrectly. Debug by checking how executor.ts successfully calls walletClient.writeContract — compare parameter passing patterns.

- **Price push failing for EUR/GBP/JPY/GOLD**: Contract revert `Best ask price is not present for the timestamp`. The Pyth Lazer subscription requests bestAskPrice but these synthetic/FX feeds may not support it. The PythLazerFeedProvider contract validates bestAskPrice presence. May need to check if the Lazer subscription config should differ for FX feeds, or if the contract has a different validation path.

- **Possible root cause for both**: The rawUpdate bytes from the WS may be a multi-feed bundle. The `updatePrice(token, rawUpdate)` contract expects per-token data. The WS binary message contains ALL subscribed feeds in one payload. The contract may need the full payload (it extracts by feedId internally), OR may need per-token data. Check how the order-execution-keeper's oracle.ts handles this — it caches the same rawUpdate for ALL tokens (line 86-92 in oracle.ts), so the full-bundle approach should work.
</blockers>
