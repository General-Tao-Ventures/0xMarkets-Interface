  **Add page-aware SWR revalidation to SyntheticsEventsProvider:**

  Per locked user decision: "Only refresh data if user is currently on the relevant page (pools page for deposits/withdrawals, trade page for orders) -- no background data fetching for other pages."

  1. Import `useSWRConfig` from "swr" and `useLocation` from "react-router-dom" at top of SyntheticsEventsProvider.tsx
  2. Inside the SyntheticsEventsProvider component:
     ```typescript
     const { mutate: globalMutate } = useSWRConfig();
     const { pathname } = useLocation();
     ```

  3. Create TWO page-aware debounced refresh helpers plus a universal token balance refresh, using separate `useRef` timers:
     ```typescript
     const poolRefreshTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
     const positionsRefreshTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

     // Revalidates token balances (universal -- balances shown on both pages)
     const triggerBalanceRefresh = useCallback(() => {
       globalMutate(
         (key: unknown) => Array.isArray(key) && key[1] === "useTokenBalances",
         undefined,
         { revalidate: true }
       );
     }, [globalMutate]);

     // Pool data refresh -- only when user is on /pools or /pools/details
     const triggerPoolRefresh = useCallback(() => {
       triggerBalanceRefresh();
       if (!pathname.startsWith("/pools")) return;
       if (poolRefreshTimerRef.current) return;
       poolRefreshTimerRef.current = setTimeout(() => {
         poolRefreshTimerRef.current = null;
         globalMutate(
           (key: unknown) => Array.isArray(key) && key[1] === "useMarketTokensData",
           undefined,
           { revalidate: true }
         );
       }, 300); // 300ms debounce
     }, [globalMutate, pathname, triggerBalanceRefresh]);

     // Positions data refresh -- only when user is on /trade
     const triggerPositionsRefresh = useCallback(() => {
       triggerBalanceRefresh();
       if (!pathname.startsWith("/trade")) return;
       if (positionsRefreshTimerRef.current) return;
       positionsRefreshTimerRef.current = setTimeout(() => {
         positionsRefreshTimerRef.current = null;
         globalMutate(
           (key: unknown) => Array.isArray(key) && key[1] === "usePositionsData",
           undefined,
           { revalidate: true }
         );
       }, 300); // 300ms debounce
     }, [globalMutate, pathname, triggerBalanceRefresh]);
     ```

  4. Add the CORRECT refresh call in each event handler, right after the existing status update calls:

     **Deposit events (call triggerPoolRefresh -- pools page data):**
     - `DepositExecuted` handler: add `triggerPoolRefresh();` after `setDepositStatuses(...)`
     - `DepositCancelled` handler: add `triggerPoolRefresh();` after `setDepositStatuses(...)`
     - `GlvDepositExecuted` handler: add `triggerPoolRefresh();` after `setDepositStatuses(...)`
     - `GlvDepositCancelled` handler: add `triggerPoolRefresh();` after `setDepositStatuses(...)`

     **Withdrawal events (call triggerPoolRefresh -- pools page data):**
     - `WithdrawalExecuted` handler: add `triggerPoolRefresh();` after `setWithdrawalStatuses(...)`
     - `WithdrawalCancelled` handler: add `triggerPoolRefresh();` after `setWithdrawalStatuses(...)`
     - `GlvWithdrawalExecuted` handler: add `triggerPoolRefresh();` after `setWithdrawalStatuses(...)`
     - `GlvWithdrawalCancelled` handler: add `triggerPoolRefresh();` after `setWithdrawalStatuses(...)`

     **Order events (call triggerPositionsRefresh -- trade page data):**
     - `OrderExecuted` handler: add `triggerPositionsRefresh();` after `setOrderStatuses(...)`
     - `OrderCancelled` handler: add `triggerPositionsRefresh();` after `setOrderStatuses(...)`

  5. Add cleanup in a useEffect to clear both timers on unmount:
     ```typescript
     useEffect(() => {
       return () => {
         if (poolRefreshTimerRef.current) clearTimeout(poolRefreshTimerRef.current);
         if (positionsRefreshTimerRef.current) clearTimeout(positionsRefreshTimerRef.current);
       };
     }, []);
     ```

  **IMPORTANT:** The `eventLogHandlers.current = { ... }` object is reassigned on every render (not wrapped in useMemo/useCallback). This means triggerPoolRefresh/triggerPositionsRefresh can be called directly inside handler bodies without needing to be in the dependency array of anything -- they are always fresh since the handlers object is recreated each render.

  **NOTE on SWR key matching:** The key matcher function receives the full SWR key. For multicall hooks, keys are arrays like `[chainId, "useMarketTokensData", ...]`. The `key[1]` check matches the hook name. Verify the exact token balance SWR key by searching: `grep -rn "useTokenBalances\|useTokensData" src/domain/synthetics/tokens/` to find the exact SWR key name used.

  **NOTE on pathname:** `pathname` is read via `useLocation()` from react-router-dom, which is already available in the component tree (SyntheticsEventsProvider is rendered inside the router). The pools page uses `/pools` and `/pools/details` routes. The trade page uses `/trade` and `/trade/:tradeType?`. Using `pathname.startsWith()` covers all sub-routes.
